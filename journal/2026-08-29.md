# 2026-08-29

## Static demo UI

Added a dependency-free browser demo under `docs/`.

The UI simulates the first deep research workflow:

- request intake;
- planning Activity;
- parallel fake agent Activities for `web`, `systems`, and `critic`;
- optional one-time Activity failure;
- Temporal-managed retry path;
- synthesis Activity;
- final `ResearchBrief` state.

This is intentionally a visual simulation rather than a real Temporal client UI.
That keeps the project aligned with the interview-prep constraint: teach Temporal
state, retry, and orchestration semantics before adding web framework or backend
integration complexity.

Next step remains durable approval: add Signal and Query support to
`ResearchWorkflow`, then update the demo to show the approval wait state.

## GitHub Pages preparation

Moved the static demo from `demo/` to `docs/` so the repository can publish it
with GitHub Pages from `main` / `docs` without a build step.

Added `docs/.nojekyll` because the site is plain HTML/CSS/JS and does not need
Jekyll processing.
