# 2026-08-29

## Static demo UI

Added a dependency-free browser demo under `docs/`.

The UI simulates the first deep research workflow:

- request intake;
- planning Activity;
- parallel fake agent Activities for `web`, `systems`, and `critic`;
- optional one-time Activity failure;
- Temporal-managed retry path;
- synthesis Activity;
- final `ResearchBrief` state.

This is intentionally a visual simulation rather than a real Temporal client UI.
That keeps the project aligned with the interview-prep constraint: teach Temporal
state, retry, and orchestration semantics before adding web framework or backend
integration complexity.

Next step remains durable approval: add Signal and Query support to
`ResearchWorkflow`, then update the demo to show the approval wait state.

## GitHub Pages preparation

Moved the static demo from `demo/` to `docs/` so the repository can publish it
with GitHub Pages from `main` / `docs` without a build step.

Added `docs/.nojekyll` because the site is plain HTML/CSS/JS and does not need
Jekyll processing.

## Pages root redirect

GitHub Pages was enabled from the repository root on `main`, so the root Pages
URL initially rendered the repository README instead of the demo.

Added a root `index.html` redirect to `docs/` and a root `.nojekyll` marker so
`https://lxjuly.github.io/temprun/` opens the demo while the Temporal service
and worker remain local.

## Tailscale Serve deployment

Configured Tailscale Serve for tailnet access to the static demo:

```text
https://xiangs-mac-studio.tail1aa4f.ts.net/
  -> http://127.0.0.1:8788
  -> Python static server
  -> temprun demo UI
```

The macOS Tailscale app could not serve the `docs/` directory directly because
path serving is blocked by app sandbox restrictions. The working setup uses a
local Python static server on `127.0.0.1:8788`, then Tailscale Serve proxies the
tailnet HTTPS URL to that port.

Made the static server persistent with:

```text
~/Library/LaunchAgents/com.temprun.demo.plist
~/.local/bin/temprun-demo-server
~/.local/share/temprun-demo/
```

The served copy lives outside the iCloud Drive workspace because launchd hit
macOS privacy restrictions when serving files directly from the workspace path.

Next step: replace the static Python server with a small local API bridge that
serves the same UI and exposes `/api/*` routes backed by the Temporal Python
client.
